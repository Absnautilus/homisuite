# Homisuite logos

Official Homisuite logo assets.

## Files

- `homisuite-icon.svg` — primary colored icon with subtle gradients.
- `homisuite-icon-flat.svg` — flat production-friendly icon.
- `homisuite-mark-purple.svg` — purple mark on transparent background.
- `homisuite-mark-white.svg` — white mark on transparent background.
- `homisuite-icon-monochrome.svg` — black-and-white icon.

## Brand color

Primary purple: `#9D47F4`

## Usage

- Use `homisuite-icon.svg` for brand presentations and larger surfaces.
- Use `homisuite-icon-flat.svg` for small UI sizes, favicons, project icons, and places where gradients are unnecessary.
- Use `homisuite-mark-purple.svg` on light backgrounds.
- Use `homisuite-mark-white.svg` on dark or purple backgrounds.
- Use `homisuite-icon-monochrome.svg` where color is unavailable.

Keep the proportions intact and do not distort, rotate, or recolor the mark outside the approved brand variants.
